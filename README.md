# Mefo privacy policy

Public privacy and support information for the Mefo iPhone app.

Published at [Mefo privacy policy](https://stickkb.github.io/Mefo-privacy/). GitHub Pages publishes `main` from the repository root. The previous policy URL forwards here so older installed versions keep a working privacy link.

The site is plain HTML and CSS with no scripts, external assets or build dependencies. The application repository remains private. No application code, tester information, signing files, credentials or private phone numbers belong here. The developer contact address is intentionally public support information.

Preview with `python3 -m http.server 8000 --bind 127.0.0.1`. Keep the data-practice statements aligned with the policy bundled in Mefo. Check keyboard focus, readable light/dark colors, links and narrow-screen layout before publishing.
