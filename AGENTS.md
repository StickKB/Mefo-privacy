# Privacy site maintenance

This selected repository publishes the Mefo privacy policy through GitHub Pages from `main` at the repository root. It contains only static HTML/CSS and `.nojekyll`; no package manager or build is required.

- Follow the user's global operating preferences and direct authorization for publication.
- Keep disclosures aligned with implemented app behavior. Do not invent domains, contact addresses, legal entities, data collection or purchase flows.
- The support email already published in the policy is intentional public contact information. Keep credentials, tester details and private application files out of this public repository.
- Preserve an accessible fallback link when maintaining compatibility redirects from previous policy locations.
- Preview with `python3 -m http.server 8000 --bind 127.0.0.1`; inspect narrow/expanded layouts, light/dark contrast and keyboard focus. Validate HTML structure, link destinations and live HTTP after publication.
- Commit only coherent verified changes under the user's authorization. Do not rewrite history or silently broaden the privacy policy.
